# Pond sounds (CC0)

Recordings under CC0 1.0 (public domain) from OpenGameArt; `Tools/audio/Water.cs` turns them into `KotH.Game/Resources/Sounds`.
- `sfx100v2_footstep_wet_01..03.ogg` (wading steps): "100 CC0 SFX #2", https://opengameart.org/content/100-cc0-sfx-2
- `splash2.wav` (landing in the pond): "Water Splash and sand footsteps" by Peludo,
  https://opengameart.org/content/water-splash-and-sand-footsteps
